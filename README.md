# NanoWall — English Nanotechnology Feedback

Интерактивная стена отзывов на уроке английского языка (тема — Nanotechnology).
Студенты пишут отзыв по QR-коду со своих телефонов; преподаватель показывает все сообщения на экране. Стена обновляется автоматически каждые 2 секунды.

## Разместить бесплатно в интернете (GitHub + Streamlit Community Cloud)

### 1. GitHub

1. Перейдите на https://github.com/new и создайте новый репозиторий `nanowall-english`.
2. Выберите **Public**, не добавляйте файлы для инициализации (README, .gitignore и license), нажмите **Create repository**.
3. В пустом репозитории выберите **uploading an existing file** (или **Add file → Upload files**). Перетащите из распакованной папки `app.py`, `requirements.txt`, `README.md`, `.gitignore` и папку `.streamlit` с файлом `config.toml`.
4. Убедитесь, что `app.py` и `requirements.txt` находятся в **корне репозитория** (не в дополнительной папке `nanowall_github`).
5. Нажмите **Commit changes**.

### 2. Streamlit Cloud

1. Перейдите на https://share.streamlit.io/ и авторизуйтесь через GitHub.
2. Нажмите **Create app → Yup, I have an app**.
3. Выберите репозиторий `nanowall-english`, ветку `main`, файл `app.py`.
4. Придумайте доступное имя, например `nanowall-english-class`, и нажмите **Deploy**.
5. Скопируйте полученную ссылку вида `https://<ваше-имя>.streamlit.app/`.

### 3. Использование на уроке

- **На проекторе:** открываете общую ссылку, видите стену отзывов и QR-код.
- **На телефонах студентов:** сканируют QR-код или переходят по ссылке `https://<ваше-имя>.streamlit.app/?view=student`.
- Студент пишет одно предложение на английском языке и жмёт `Send feedback`; оно появляется на проекторе автоматически.
- Перед уроком убедитесь, что сайт открыт и работает. Не требуется запускать Python или держать ваш компьютер в качестве сервера.

**Важно:** для простоты отзывы хранятся во временной SQLite-базе на сервере Streamlit. После перезапуска приложения или остановки хостинга они могут исчезнуть. Для одного занятия этот вариант удобен, но для постоянного архива понадобится внешняя БД.

Официальная документация Streamlit по публикации: https://docs.streamlit.io/deploy/streamlit-community-cloud/deploy-your-app/deploy
